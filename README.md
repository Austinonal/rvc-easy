# RVC Easy

แปลงเสียงด้วยโมเดล RVC (Retrieval-based Voice Conversion) แบบง่าย: เปิดหน้าเว็บ → อัปโหลดเสียง + ไฟล์โมเดล `.pth` → กดแปลง

ระบบเดียวกับโน้ตบุ๊ก "RVC Crepe v2" เดิม (ใช้ RVC + hubert + rmvpe/crepe/harvest) แต่ตัดส่วนเทรน, Google Drive, Sheets ออก เหลือ **แปลงเสียง** กับ **ทำเพลงคัฟเวอร์** (แยกเสียงร้อง/ดนตรีด้วย UVR MDX-Net แล้วแปลงเสียงร้อง รวมกลับ) และใช้ [rvc-python](https://github.com/daswer123/rvc-python) เป็นเครื่องยนต์แทนการ clone repo ทั้งก้อน

## วิธีที่ 1: Google Colab (ไม่หนักเครื่องเลย)

1. เปิด `colab.ipynb` ใน Colab (อัปโหลดไฟล์นี้ หรือเปิดผ่านลิงก์ GitHub)
2. **รันไทม์ → เปลี่ยนประเภทรันไทม์ → T4 GPU**
3. แก้ `REPO` ในเซลล์แรกให้เป็น URL repo นี้ แล้วรันเซลล์ 1 และ 2
4. กดลิงก์ `gradio.live` ที่ขึ้น

## วิธีที่ 2: รันในเครื่อง (CPU ก็ได้ แต่ช้ากว่า)

ต้องใช้ **Python 3.10** (ไลบรารีที่ใช้ล็อกแพ็กเกจรุ่นเก่า ไม่ติดตั้งบน 3.12+)

```bash
pip install uv
uv venv --python 3.10 .venv
# Windows: .venv\Scripts\activate    Mac/Linux: source .venv/bin/activate
uv pip install -r requirements.txt
python app.py
```

เปิดเบราว์เซอร์ตามที่ขึ้นใน terminal (ปกติ http://127.0.0.1:7860)

> การรันครั้งแรก ระบบจะดาวน์โหลดโมเดลพื้นฐาน (hubert_base.pt, rmvpe.pt) ประมาณ 300 MB ให้อัตโนมัติ

## ทำเพลงคัฟเวอร์

แท็บ **ทำเพลงคัฟเวอร์**: อัปโหลดเพลงเต็ม + โมเดล `.pth` แล้วกดปุ่มเดียว ระบบจะแยกเสียงร้อง/ดนตรี → แปลงเสียงร้อง → รวมกลับ ได้ 3 ไฟล์: เพลงรวม, เสียงร้องที่แปลงแล้ว, ดนตรีล้วน (กดปุ่มดาวน์โหลดที่ตัวเล่นเสียงเพื่อเก็บไฟล์)

> บน Colab ไฟล์ทั้งหมดหายเมื่อปิดเซสชัน อย่าลืมดาวน์โหลดผลลัพธ์ก่อนปิด และต้องอัปโหลดโมเดลใหม่ทุกครั้ง

## วิธีใช้ (แท็บแปลงเสียง)

| ช่อง | คืออะไร |
|---|---|
| ไฟล์เสียงต้นฉบับ | เสียงที่อยากแปลง (wav/mp3) |
| โมเดล `.pth` | โมเดลเสียงปลายทาง (ต้องเป็นโมเดล RVC) |
| `.index` | ไม่บังคับ ถ้ามีจะเหมือนต้นเสียงขึ้น |
| ปรับระดับเสียง | ชาย→หญิง ใช้ +12, หญิง→ชาย ใช้ -12, เสียงเพศเดียวกัน ใช้ 0 |
| วิธีหา pitch | `rmvpe` แนะนำ, `crepe` ละเอียดแต่ช้า, `harvest` ช้า, `pm` เร็วสุดแต่หยาบ |

## ข้อจำกัด

- **ไม่มีการเทรนโมเดล** ต้องมีไฟล์ `.pth` ที่เทรนไว้แล้ว
- ต้องใช้ Python 3.10 (ดูเหตุผลใน `requirements.txt`)
- ใช้กับเสียงที่คุณมีสิทธิ์ใช้เท่านั้น อย่าใช้ปลอมแปลงเสียงบุคคลอื่นโดยไม่ได้รับอนุญาต
